# Data Model

Persistence uses SQLite with Drizzle ORM. Schema is defined in `backend/src/schema.ts` and mapped in `backend/src/db.ts`.

## Table: locations

Primary fields:

- `id` integer primary key (auto increment)
- `latitude` real not null
- `longitude` real not null
- `created_at` text not null

A unique index enforces one row per normalized coordinate pair:

- `locations_latitude_longitude_unique (latitude, longitude)`

## Weather Snapshot Columns

The row stores a denormalized weather snapshot:

- condition + provenance: `condition`, `observed_at`, `source`, `area`, `valid_period_text`
- current readings: `temperature_c`, `humidity_percent`, `rainfall_mm`
- wind readings: `wind_speed_knots`, `wind_direction_degrees`
- forecast summary: `forecast_low_c`, `forecast_high_c`, `forecast_periods`
- environment and air quality: `uv_index`, `psi_twenty_four_hourly`, `pm25_one_hourly`, `air_quality_region`
- daily outlook: `daily_forecast`

`forecast_periods` and `daily_forecast` are stored as JSON text columns.

## Defaults

On initial location create (before successful refresh), weather defaults to:

- `condition`: `Not refreshed`
- `source`: `not-refreshed`
- most numeric fields: `null`
- list fields: empty arrays
